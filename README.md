Fiber Science Lab Assistant

An educational web application for second-year Textile Engineering students.

Features

- Professional textile laboratory color theme
- Fiber explorer and classification
- Natural, synthetic and regenerated fiber information
- Fiber properties, composition and uses
- Side-by-side fiber comparison
- Interactive MCQ quiz
- Simple explanations for students

Fibers Included

- Cotton
- Wool
- Silk
- Flax
- Polyester
- Nylon
- Viscose
- Acrylic

Technologies

- Python
- Streamlit
- Custom CSS

Project Structure

fiber-science-app/
├── app.py
├── requirements.txt
└── README.md

Installation

Install the dependencies:

pip install -r requirements.txt

Run the Application

streamlit run app.py

The app will open in your web browser.

Intended Users

Second-year Textile Engineering students studying Fiber Science and laboratory identification.

Safety Note

Fiber identification tests must follow the university laboratory manual and instructor's directions. Never perform burn or chemical tests without proper supervision.
